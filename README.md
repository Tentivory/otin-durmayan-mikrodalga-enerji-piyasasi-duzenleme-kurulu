# otin-durmayan-mikrodalga-enerji-piyasasi-duzenleme-kurulu
Mikrodalganın yemek bitince ötmeyi bırakmamasını resmi enerji krizi, milli bip egemenliği ihlali ve tarife protokolü sapması sayan; tabağı santral, 'az kalsın kapağı açardım' cümlesini kesinti tutanağı ilan eden Kurul. Gerçekten çalışır. Fırınlar artık şebekedir.
